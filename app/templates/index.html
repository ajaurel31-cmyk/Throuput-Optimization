Common Bottleneck Causes
Reference: Why you might only get 50 MB/s on a 10G pipe

Layer 1-2 (Physical/Data Link):
  • Speed/duplex mismatch (e.g., 1G negotiated on a 10G port)
  • Bad SFP/transceiver or cable (CRC errors, input errors)
  • Half-duplex anywhere in the path

Layer 3 (Network):
  • MTU mismatch causing fragmentation or PMTUD black hole
  • Jumbo frames enabled on some devices but not all
  • Suboptimal routing (asymmetric path, extra hops)

Layer 4 (Transport):
  • TCP window size too small for bandwidth-delay product
  • TCP MSS clamping reducing segment size
  • Single TCP stream (need parallel streams for high BDP)
  • TCP congestion control algorithm not suited for long fat pipes

Firewall / Security:
  • SSL/TLS decryption (50-80% throughput hit)
  • IPS/IDS inspection overhead
  • Session table exhaustion
  • Firewall CPU saturation

QoS / Traffic Management:
  • Traffic shaper or policer capping bandwidth
  • Wrong QoS queue assignment (best-effort instead of priority)
  • Output queue drops on congested interfaces

Server / Application:
  • Disk I/O bottleneck on source or target server
  • NIC offload disabled (TSO, GRO, LRO)
  • CPU bottleneck on server (single-threaded transfer)
  • Small socket buffer sizes
